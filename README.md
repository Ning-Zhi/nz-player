# NZ播放器 —— 无人值守直播播放器 v0.3

Android 电视盒子的**自愈型直播播放器**：锁定频道断流自动重连、卡死自愈、崩溃自启、开机自启；
频道侧边栏（收藏 + 按省份分组）、长按收藏、应用内添加频道。内置 117 个频道（山东为主，含已验证源）。
设计文档见 `项目1.txt`。（工程内部包名沿用 com.shoubo.tv，界面显示名：NZ播放器）

## 二、界面操作（v0.2）

| 操作 | 鼠标 | 遥控器 | 效果 |
|---|---|---|---|
| 呼出/关闭频道栏 | 点左上角「☰ 频道」 | 菜单键 | 收藏 + 按省份分组的频道列表 |
| 切台 | 点击列表里的频道 | 频道+/-键 | 切换后自愈引擎继续守护新频道 |
| 收藏/取消收藏 | **长按**列表里的频道 | — | 出现/消失 ★，同时收进顶部「★ 收藏」分组 |
| 添加频道 | 频道栏右上「＋ 添加」 | — | 输入**名称 + m3u8 地址**即添加，归入「自定义」分组 |
| 状态栏 | 单击画面 | OK键 | 播放状态/运行统计，5秒无操作自动隐藏 |
| 返回 | — | 返回键 | 先关频道栏；再按退到后台（不退出） |

> 防误触：`config.json → lock.channel_lock: true` 时，点击列表不切台（长按收藏仍可用）。
> 所有应用内改动（添加/收藏/切台）都会写回 `/sdcard/守播/config.json`，换盒子拷贝配置即可迁移。

## 三、获取 APK

### 方式1：GitHub Actions 云端打包（推荐）

1. GitHub 新建仓库，把 `shoubo` 文件夹**全部内容**上传（注意包含隐藏文件夹 `.github`）；
2. 仓库 Actions 标签等待 "Build APK" 跑完（约3-5分钟）；
3. 该次运行底部 Artifacts 下载 `shoubo-debug-apk`，解压得 `app-debug.apk`。

### 方式2：Android Studio 本地打包

打开 `shoubo` 文件夹，Sync 完成后 `Build → Build APK(s)`（已内置阿里云镜像，国内可直接构建）。

### 安装到盒子（腾讯极光 6se：H618/H313）

```bash
adb connect 盒子IP:5555
adb install -r app-debug.apk
```

首次部署必做：屏幕永不休眠；允许自启动；Android 11+ 建议
`adb shell appops set com.shoubo.tv MANAGE_EXTERNAL_STORAGE allow`；强烈建议网线直连。

## 四、配置说明

配置文件：`/sdcard/守播/config.json`（首次启动自动生成；改完保存即热加载）。

| 字段 | 说明 |
|---|---|
| `channels[].primary_url` | 主播放地址（m3u8 / http-ts 均可） |
| `channels[].backup_url` | 同频道备用源（二期启用，现为空） |
| `channels[].category` | **省份/分组名**（侧边栏按它分组；"央视""卫视"排最前，"自定义""其他"垫底） |
| `channels[].headers` | 自定义请求头，如防盗链的 User-Agent / Referer |
| `current_channel_id` | 上次播放的频道（启动自动恢复） |
| `favorites` | 收藏的频道 ID 数组（应用内长按也会改这里） |
| `m3u_file` | 可选。如 `/sdcard/守播/channels.m3u`，`group-title` 会作为分组名 |
| `resilience.*` | 重连节奏、卡死阈值、探测周期 |
| `lock.channel_lock` | 频道锁定（true=列表只读，防误触；默认 false） |

## 六、快速验收（对应文档第5章）

1. 拔网线 30 秒再插回：状态栏"信号中断→自动重连"，恢复后回到原频道；
2. 断网 10 分钟：显示"网络已断开，正在等待恢复…"，恢复后自动续播；
3. `adb shell am force-stop com.shoubo.tv`：3 秒后自动拉起并继续播；
4. 盒子断电重启：开机自动进入播放；
5. 侧边栏：长按任意频道出现 ★ 并进入"收藏"分组；"＋添加"输入名称+地址后列表立即可见。
